# Changelog

## 1.1.0

- Renamed from JevControllerKeyboard to JevOnScreenKeyboard. The settings file is now JevMods.JevOnScreenKeyboard.cfg, so set Scale again if you changed it.

## 1.0.0

- First release.
- On-screen keyboard for gamepads that opens when a text field gets focus.
- Native layouts for the game's languages, with accent variants on RT.
- Korean syllables, Japanese kana and kanji suggestions, Chinese pinyin.
- Xbox, PlayStation and Switch button glyphs.
